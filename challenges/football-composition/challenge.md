# Football Composition

## Contexte
Tu dois créer une page web autonome (un seul fichier HTML) qui visualise la composition d'une équipe de football sur un terrain, avec les 11 joueurs positionnés selon un schéma tactique.

## Consigne
- Utilise le schéma tactique **4-3-3** (4 défenseurs, 3 milieux, 3 attaquants)
- Affiche un terrain de foot vu du dessus (rectangle vert avec surface de réparation, rond central, etc.)
- Positionne chaque joueur à son emplacement sur le terrain
- Chaque joueur doit afficher : son numéro, son nom, et son poste (Gardien / Défenseur / Milieu / Attaquant)
- Le gardien doit être facilement identifiable (couleur différente)
- Aucune librairie externe (tout en HTML/CSS/JS inline)
- Le design doit être propre, responsive et agréable
- Tu peux inventer les noms des joueurs (une équipe de ton choix, réelle ou fictive)

## Critères d'évaluation
- Le terrain est bien proportionné et ressemble à un vrai terrain de foot
- Les joueurs sont positionnés correctement selon le schéma 4-3-3
- Chaque joueur affiche numéro, nom et poste
- Le design est soigné (couleurs, typographie, espacement)
- La page est responsive et fonctionne sur mobile

## Format de sortie attendu
- `index.html` : la page complète (HTML + CSS + JS inline)
