# Hello World

## Contexte
Tu découvres un nouveau projet. Ta mission est de créer une page HTML simple qui affiche un compteur interactif.

## Consigne
Crée un fichier `index.html` dans le dossier de résultats avec :
- Un titre "Compteur interactif"
- Un bouton "+" qui incrémente un compteur
- Un bouton "-" qui décrémente
- Le compteur ne descend jamais en dessous de 0
- Un bouton "Reset" pour remettre à 0
- Style CSS sobre et moderne (pas de framework)

## Critères d'évaluation
- Le compteur fonctionne correctement
- Le design est propre et responsive
- Le code est valide HTML5
- Aucune erreur JavaScript dans la console

## Format de sortie attendu
- `index.html` : la page complète (HTML + CSS + JS inline)
